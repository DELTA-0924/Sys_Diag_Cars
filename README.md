# 🚗 AI-based Vehicle Diagnostic System

Система диагностики автомобилей, использующая **искусственный интеллект** для анализа данных с OBD-II датчиков. Веб-сервер построен на **FastAPI** с полностью асинхронным кодом и взаимодействует с базой данных **PostgreSQL**.

> ⚠️ **Модель машинного обучения не включена в данный репозиторий.**

---

## 📦 Стек технологий

- **FastAPI** – высокопроизводительный асинхронный веб-фреймворк
- **PostgreSQL** – надежная реляционная база данных
- **Pydantic** – валидация и сериализация данных
- **Mailtrap** – тестовая отправка писем для подтверждения email
- **Pip** – менеджер зависимостей Python
- **pydantic-settings** – управление конфигурациями

---

## 🛠 Установка и запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/your-username/vehicle-diagnostics.git
   cd vehicle-diagnostics
   ```

2. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения:**

   Создайте файл `.env` в корневой директории и добавьте необходимые конфигурации (например, доступ к базе данных, Mailtrap и JWT-секреты).

4. **Запустите приложение:**

   ```bash
   python -m src.main
   ```

---

## 🔐 Авторизация

- Поддержка **JWT-токенов** для безопасной авторизации
- Регистрация пользователей с подтверждением email через **Mailtrap**
- Вход и обновление токенов для длительных сессий

---

## 🧠 Искусственный интеллект

- Интеграция с внешней моделью машинного обучения для анализа данных OBD-II
- API адаптировано для работы с предсказаниями модели
- Архитектура поддерживает подключение моделей через **REST** или **gRPC**
- Модель машинного обучения **не включена** в данный репозиторий

---

## 🧾 Сущности базы данных

- **Машины**: информация о транспортных средствах (VIN, марка, модель и т.д.)
- **OBD-II Датчики**: данные с сенсоров (скорость, обороты двигателя, температура, коды ошибок и др.)
